**Пагинация (pagination) в Django Rest Framework (DRF)** — это разбивка больших объёмов данных на страницы для удобства просмотра.

## 📄 Зачем пагинация

Без пагинации DRF вернёт **все объекты**.
Если их сотни — клиент «повиснет», а сервер потратит ресурсы на передачу ненужных данных.

Пагинация:

- делит ответы на страницы (`?page=1`, `?page=2`);

- ограничивает объём (`PAGE_SIZE=10`);

- может позволять пользователю управлять размером (`?page_size=50`).


Например, ты получаешь не весь список клиентов, а:
```json
{   "count": 120,
	"next": "http://127.0.0.1:8000/api/clients/?page=2",
	"previous": null,
	"results": [     {"id": 1, "name": "Test", "email": "t@example.com"},
	...   ]
}
```


#### Пагинация делает API стабильным при росте базы.

📘 _Итог:_
Ты подключил `DEFAULT_PAGINATION_CLASS` и (опционально) кастомный пагинатор, чтобы контролировать `page_size` и ограничить нагрузку.
