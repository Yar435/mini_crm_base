**Фильтрация в Django Rest Framework (DRF)** — это инструмент для контроля данных, возвращаемых API, на основе определённых критериев.
## 🔍 Зачем фильтрация в Django REST Framework

Когда у тебя появляются **списки данных** (например, клиенты, сделки, пользователи), без фильтрации ты вынужден возвращать _всё подряд_.
На реальном проекте это приводит к трём проблемам:

1. **Перегрузка API** — если в таблице 10 000 записей, отдавать их все одним запросом нельзя.

2. **Невозможность поиска** — пользователь хочет увидеть только сделки конкретного менеджера или клиентов с именем `"Иван"`.

3. **Повторная логика** — без фильтров ты бы вручную обрабатывал `?client_id=...` и `?status=...` в `get_queryset()`.


Поэтому DRF даёт встроенный механизм:

- `filterset_fields` — точные фильтры `?status=new`;

- `search_fields` — полнотекстовый поиск `?search=acme`;

- `ordering_fields` — сортировка `?ordering=-amount`.


📘 _Итог:_
Ты подключил эти фильтры через `django-filter` и DRF backend’ы.
Теперь любые ViewSet’ы автоматически поддерживают query-параметры вроде:

```sql
/api/deals/?status=new&search=alex&ordering=-amount
```
