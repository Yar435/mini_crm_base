**Определение:**
Миксин — это вспомогательный класс, который добавляет *частичное поведение* другим классам через множественное наследование.
Не предназначен для самостоятельного использования.

**Зачем нужен:**
Позволяет избежать дублирования кода и гибко расширять функционал классов (например, в Django CBV или DRF ViewSet).

**Примеры:**
```python
from django.views.generic import View

class JsonResponseMixin:
    def render_to_json(self, data):
        return JsonResponse(data)

class MyView(JsonResponseMixin, View):
    def get(self, request):
        return self.render_to_json({"status": "ok"})
        ```

**Где применяется:**

- Django CBV (`TemplateResponseMixin`, `ContextMixin`, и т.д.)

- Django REST Framework (`ListModelMixin`, `CreateModelMixin`, `RetrieveModelMixin`, ...)


**Ключевая мысль:**

> Миксин — это “поведение”, а не “сущность”.
> Он не самостоятельный класс, а добавка к другим.
