# Git — базовые принципы и понятия

## 🔹 Что такое Git
**Git** — распределённая система контроля версий (VCS), созданная для отслеживания изменений в коде.
Главная идея: каждый разработчик имеет **локальную копию** всей истории проекта.

Git позволяет:
- хранить историю изменений (commit history),
- откатываться на нужные версии,
- работать параллельно в ветках (branching),
- синхронизироваться с удалённым репозиторием (remote).

---

## 📁 Структура Git-репозитория
После `git init` в папке появляется скрытый каталог `.git/`.
Он содержит всё, что нужно для восстановления истории.

Основные состояния файлов:

|  Состояние | Описание |
| ------ | ------ |
| **Untracked** | файл новый, Git о нём не знает |
| **Staged** | файл добавлен в индекс (`git add`) |
| **Committed** | изменения записаны в историю (`git commit`) |

---

## 🔄 Основной цикл работы
1. **Редактирование файлов** → файлы `untracked` / `modified`
2. **Добавление в индекс:**
   ```bash
   git add <имя файла>      # или . чтобы добавить всё
   ```
3. Фиксация изменений:
```bash
git commit -m "описание изменений"
```
4. Синхронизация с репозиторием:
```bash
git push origin main
```

Для загрузки новых изменений от других:
```bash
git pull origin main
```

## 🌿 Ветки (Branches)

Ветка — это указатель на коммит.
`main` (или `master`) — основная ветка, в которой хранится стабильная версия проекта.

Создать новую ветку:
```bash
git checkout -b feature/auth
```

Переключиться:
```bash
git checkout main
```

Слить ветку обратно:

```bash
git merge feature/auth
```

Удалить локальную ветку:
```bash
git branch -d feature/auth
```

---
## 🧠 HEAD, коммиты и история

**HEAD** — это текущий указатель на активную ветку или конкретный коммит.

Посмотреть историю:

```bash
git log --oneline --graph --decorate
```

Посмотреть изменения:

```bash
git diff
```


---

## 🔗 Связь с удалённым репо

Подключение:
```bash
git remote add origin https://github.com/user/repo.git`
```

Проверить:
```bash
git remote -v
```

Отправка изменений:

```bash
git push -u origin main
```

## 🚨 Откаты и исправления

Отменить добавление в индекс:
```bash
git reset HEAD <file>
```

Откатить локальные изменения:
```bash
git checkout -- <file>
```

Откат к предыдущему коммиту:
```bash
git reset --hard <commit_hash>
```

---

## 💡 Полезные советы

- Держи коммиты атомарными — одно логическое изменение = один коммит.
- Пиши осмысленные сообщения коммитов:
```bash
    feat: добавил JWT авторизацию
    fix: исправил баг с пагинацией
    docs: обновил README
```
- Используй `.gitignore` для исключения файлов (venv, **pycache**, .env, и т.п.).
- Перед `push` выполняй `git pull` и проверяй `git status`.

---
## 📚 Дополнительно

- `git stash` — временно убрать изменения
- `git tag` — метки версий (например, v1.0.0)
- `git clone` — копирование удалённого репо
- `git rm` / `git mv` — удаление и переименование
