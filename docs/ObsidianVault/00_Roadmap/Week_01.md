## ⚙️ Практика

#### -Проект: **mini_crm_base**
- Создай новое Django-приложение в PyCharm.
- Подключи PostgreSQL через `psycopg2` (через Docker или локально).
- Реализуй три модели:
  - `Client` (имя, контакт, дата создания),
  - `Deal` (название, сумма, статус, внешний ключ на `Client`),
  - `Manager` (имя, email, телефон).
- Создай базовые CRUD-представления (views + urls) и протестируй их в браузере.
- Настрой Django Admin для всех моделей.
- Проверь, как ORM делает запросы через `QuerySet`.

**Цель практики** — собрать полностью рабочее минимальное Django-приложение с реальной БД и админкой.
