# Проект: GraphScope

## Цель
Построение графов событий из amoCRM и визуализация действий сотрудников.

## Технологии
- Django, DRF, PostgreSQL
- Redis, Celery
- Возможна интеграция с FastAPI для аналитики

## Основные задачи
- [ ] Модель событий и акторов
- [ ] Хранилище графа (PostgreSQL JSONB)
- [ ] API выдачи связей и фильтрации
- [ ] Отображение графа (веб-интерфейс позже)

## Примечания
Использовать для тренировки проектирования архитектуры и API.
